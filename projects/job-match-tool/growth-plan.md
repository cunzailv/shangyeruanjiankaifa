# 实战示例：JD-简历匹配工具的四层增长总案

> **这是什么**：拿一个真实形态的 C 端求职工具（JD 逐条匹配 + 差距清单 + 多平台投递台账），按 `references/growth-marketing-playbook.md` 的四层体系走一遍，产出可执行的总案与算过账的数字。
> **重要**：文中的定价、转化率、CPC 均为**示例假设**（标注了来源口径），不是该产品的真实财务；替换 §0 参数表后，§4 的所有结论会自动跟着变 —— 这正是这份总案的价值：**参数一改，结论立刻重算，不用重新吵一遍。**

---

## 0. 参数假设表（唯一需要你替换的地方）

| 参数 | 取值 | 口径 / 依据 |
| :--- | :--- | :--- |
| 定价 | Free（5 次匹配/月，报告带水印）/ Pro ¥39 月 / 季付 ¥99（折 ¥33 月）/ 单次深度报告 ¥19 | 对标国内 AI 简历工具常见带 |
| 混合 ARPPU/月 | ¥37 | 60% 月付 ¥39 + 40% 季付 ¥33 加权 |
| 毛利率 | 85% | LLM 调用 + 支付通道 1% + 存储 |
| 平均付费月数 | 2.5 | 求职周期 3~6 个月，成功后即流失（**任务型产品，不能用 SaaS 的留存假设**） |
| **LTV** | **¥79** | 37 × 0.85 × 2.5 |
| **CAC 上限** | **¥26** | LTV / 3 |
| 最低 ROAS | 1.18 | 1 / 毛利率（首单回收口径） |
| 激活率（注册→完成首份匹配报告） | 目标 ≥ 55% | 该产品的"aha 时刻"就是第一份差距清单 |
| 激活→付费 | 目标 12% | → 注册→付费 ≈ **6.6%~7%** |
| 月现金预算（早期） | ¥3,000 | 一人/小团队自力更生 |

> **第一个反直觉结论**：LTV 只有 ¥79，CAC 上限 ¥26。这不是"产品不行"，而是**任务型产品的结构性事实**——用户找到工作就走。所以下面 §4 会算出一个更难看的结论，而 §2 的策划与 §3 的推广必须承担主力。

## 1. ① 营销：管全局

### 1.1 ICP 分三段（不做"所有求职者"）

| 段 | 人群 | 此刻的处境 | 付费意愿 | 决策速度 | 战略角色 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **A 应届生** | 秋招 9~11 月 / 春招 3~4 月 / 寒假实习 12~1 月 | 投 100 份没回音，不知道差在哪 | 弱~中（¥39 可接受，¥299 犹豫） | 快（1 天内） | **规模与口碑**（声量主战场） |
| **B 社招跳槽** | 在职 25~35 岁，骑驴找马 | 时间少，必须高命中率，怕被现公司发现 | **强**（¥99 季付 + 精修可接受） | 快（1~2 天） | **主攻**（客单与转化最平衡） |
| **C 转行 / 被优化** | 30~40 岁，经历与目标岗错位 | 不知道怎么"翻译"自己的经历 | 很强（愿付 ¥399 辅导） | 慢（要信任） | **upsell 池**（拉高 LTV） |

**主攻 B，A 做规模，C 做提价。**

### 1.2 定位四件套

| 要素 | 内容 |
| :--- | :--- |
| **ICP** | 社招跳槽者（25~35 岁、3~8 年经验、目标岗位明确） |
| **JTBD 场景** | "我投了 30 份没回音，不知道是简历差还是岗位不对"的那一刻 |
| **替代方案** | 简历模板站 / ChatGPT 通用改写 / 人工代写（¥300~800）/ 招聘平台自带诊断 / 忍着继续海投 |
| **唯一差异** | 以 **JD 原文为评分标准**逐条对齐，输出差距清单；每条建议都能点回 JD 的那一句 |

**定位陈述**：为【社招跳槽者】在【投了没回音】时，把简历与目标 JD 逐条对齐并给出差距清单；不同于【模板站与通用 AI 改写】，我们【以 JD 为唯一评分标准】，并且【每条建议都指向 JD 原文】。

### 1.3 价值主张三层

| 层 | 内容 |
| :--- | :--- |
| **电梯稿（10 秒）** | 把 JD 粘进来，30 秒告诉你简历差哪 5 个词。 |
| **三个 Proof** | ① 100 份真实 JD 实测：平均命中率从 42% → 78%；② 用户 7 日内面试邀约率 25%（回访样本）；③ 从上传到出报告中位 4 分 20 秒。**（早期没有真实数据就写测试样本量与局限，不要编"提升 300%"）** |
| **三个反对意见** | 贵 → "一次 ¥19，代写 ¥300 起"；AI 味 → "可以关掉改写，只用对齐"；隐私 → "简历是敏感个人信息，本地解析、可一键删除、不用于训练" |

### 1.4 定价三档与锚点

| 档 | 价格 | 内容 | 作用 |
| :--- | :--- | :--- | :--- |
| 单次报告 | ¥19 | 1 份 JD 深度差距清单 | **锚点**（让 ¥39 月费显得划算） |
| Pro | ¥39/月 | 20 份 JD + 投递台账 + 版本对比 | 主推 |

### 1.5 增长模型与预算配比

**模型 = 内容驱动 + 节点脉冲**（求职需求有极强的日历性，不能全年同强度投入）。

| 阶段 | 营销（决策） | 策划（创意） | 推广（人力） | 投放（现金） |
| :--- | :--- | :--- | :--- | :--- |
| 现在（0→1，验证付费） | 30% | 30% | **60%** | **≤ ¥500/月，只验证不获客** |
| 春招峰值（3~4 月） | 20% | 20% | 40% | 预算可到 30%（若 §4 条件满足） |

### 1.6 目标数字（写死，月底对）

| 指标 | 目标 | 备注 |
| :--- | :--- | :--- |
| 自然注册 | ≥ 150 / 月（90 天内） | 低于 100 视为定位或选题有问题 |
| 激活率 | ≥ 55% | 注册→完成首份报告 |
| 付费转化 | ≥ 6.6% | 注册→付费 |

| CAC（全成本口径） | 边际 ≤ ¥26 | **看边际，不看平均**：早期人力固定，平均值必然超标（0.5 FTE ¥8,000 ÷ 150 注册 ≈ ¥53），拿平均值决策会误杀正确动作 |
| LTV:CAC | ≥ 3 | 当前 79/26 ≈ 3.0，刚好卡线 |

## 2. ② 策划：出主意

### 2.1 Big Idea（过四检验）

> **"简历不是写给你自己看的，是写给那一份 JD 看的。"**

| 检验 | 是否通过 | 说明 |
| :--- | :--- | :--- |
| 一句话说得清 | ✅ | 不带产品名也能讲明白 |
| 演得出来 | ✅ | 左 JD 右简历、差异处高亮，天然是画面 |
| 记得住 | ✅ | 一句话推翻"简历要写得漂亮"的常识 |
| 能落到 CTA | ✅ | "粘一份 JD 试试" |

### 2.2 Campaign 概念：洞察 → 冲突 → 反转 → 行动

| 要素 | 内容 |
| :--- | :--- |
| **洞察** | 你以为简历是被 HR 淘汰的，其实是被**关键词初筛**淘汰的 |
| **冲突** | 你想展示全部经历，系统只认 JD 里出现过的词 |
| **反转** | 不用重写，只要补上那 5 个词 |
| **行动** | 粘贴 JD，30 秒出差距清单 |

### 2.3 Creative Brief（9 项，可直接发给设计/剪辑）

```markdown
1. 背景：11 月秋招尾声 + 12 月寒假实习节点，投递量大但面试率低
2. 单一目标：注册（不是品牌曝光）
3. 受众：社招跳槽者 / 应届生（两版素材，分开投）
4. 单一信息：简历是被关键词筛掉的，不是被 HR 淘汰的
5. 支持点：① 100 份 JD 实测命中率 42%→78%；② 每条建议指向 JD 原文；③ 中位 4 分 20 秒出报告
6. 调性：专业、克制、不给焦虑；禁讲"保 offer / 保过 / 100% 面试"
7. 必含元素：报告截图（打码姓名）、Logo、隐私说明一行
8. 形式与规格：图文 3:4（小红书）、15s 竖版口播（抖音/B站）、对比长图（知乎）
9. 成功标准：3 秒记忆率 ≥ 40%（5 人复述测试）
```

### 2.5 两条 15s 脚本（可直接拍）

**脚本 A（反常识钩子）**

| 时间 | 画面 | 口播 |
| :--- | :--- | :--- |
| 0~3s | 黑底白字："你的简历，HR 只看了 7 秒" | "HR 看一份简历，平均 7 秒。" |

**脚本 B（结果前置钩子）**：0~4s 直接展示"命中率 78%"报告截图 → 4~10s 反向解释"这 5 个词你原本一个都没有" → 10~15s CTA "评论区回『JD』"。

### 2.6 视觉锤

- **固定主色**：深蓝（#1B3A6B）+ 白底大字。
- **固定构图**：左 JD / 右简历，中间红框标差异（这是产品最强画面，重复 100 次）。
- **固定元素**：右上角"匹配度 XX%"角标 —— 用户看到角标就知道是你。

### 2.7 策划产量要求

每周 ≥ 3 条内容（1 教学 + 1 对比/证据 + 1 短视频），每月 ≥ 8 条投放素材脚本。**产能不足，投放就没弹药，推广也没话题**——这是小团队最常见的死因。

### 3.2 小红书 SOP（主渠道，2 周养号 + 6 篇首发）

1. **W1~W2 养号**：每天 1 条有价值评论（回答"简历怎么写"类问题，不提产品）+ 收藏 3 篇同类笔记；不发文、不留联系方式。
2. **W3 首发 6 篇**（对应 §2.4 的 1/4/7/3/10/12）：封面 3 行字以内、第一句必须扎心、正文 300~500 字、结尾一句"要模板可以留言"（不在正文放链接）。
3. **评论区运营**：置顶一条"常见 3 个问题"自答；对"我也是"的评论逐条回复（这是算法加权信号）。
4. **私信承接**：统一话术 → 引导到站内免费诊断（**不要在私信发二维码，容易限流**）。
5. **复用**：一篇爆款拆成 3 条短视频 + 1 篇知乎回答。

## 4. ④ 投放：买曝光（算完再决定开不开）

### 4.1 三条线（用 §0 参数算）

| 线 | 计算 | 结果 |
| :--- | :--- | :--- |
| 目标 CPA 上限 | LTV / 3 = 79 / 3 | **¥26** |
| 最低 ROAS | 1 / 85% | **1.18**（首单回收刻度；90 天窗口目标 ≥ 1.8） |
| 日预算门槛 | 3 × 26 | **¥78/组/日** |

### 4.2 三条渠道的 CPA 实测推演（这是最关键的一张表）

| 渠道 | 假设 CPC/CPM | 点击→注册 | 注册→付费 | 推算 CPA | 对比上限 ¥26 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 搜索（百度/Google） | CPC ¥2.5 | 12% | 7% | **¥298** | **11.5 倍** ❌ |
| 小红书聚光 | CPC ¥1.2 | 15% | 7% | **¥114** | **4.4 倍** ❌ |
| 抖音信息流 | CPM ¥25 / CTR 1.2% → CPC ¥2.08 | 10% | 7% | **¥297** | **11.4 倍** ❌ |

> **结论：三条付费线全部 ≥ 4 倍于 CAC 上限，投放不成立。**
> 这不是执行力问题，是**单位经济不成立**。硬投的结果是：花 ¥3,000 买 10 个付费用户，收回 ¥370，亏 ¥2,630，还会得出"产品没需求"的错误结论。

### 4.3 那还投不投？—— 只投 ¥500/月，且只做三件事

| 用途 | 预算 | 目的 | 判定 |
| :--- | :--- | :--- | :--- |
| 品牌词防守（"XX 简历"等自有品牌词） | ¥200/月 | 防止竞品截流 | 看品牌词点击份额 |
| 2 条长尾高意图词（"按 JD 改简历""简历 关键词 匹配"） | ¥300/月 | 验证搜索侧真实 CVR | CPC ≤ ¥0.6 才继续 |
| 标准信息流 / 聚光获客 | **¥0** | — | 明确不做 |

### 4.4 什么条件下投放才成立（把条件写死，别靠感觉）

需要 **LTV ≥ 3 × 实际 CPA**。以最低的 CPA ¥114（小红书聚光）为例 → 需 LTV ≥ **¥342**，是当前 ¥79 的 4.3 倍。

| 路径 | 动作 | LTV 变化 | 是否够 |
| :--- | :--- | :--- | :--- |
| 加 upsell ① | 1v1 面试辅导 ¥399（毛利 80%，渗透 15%） | +¥48 | 不够 |
| 加 upsell ② | 简历人工精修 ¥299（毛利 70%，渗透 10%） | +¥21 | 不够 |
| 两者叠加 | 合计 | **¥148** | 仍不够（CAC 上限 ¥49 < ¥114） |
| **正解** | ① CPA 打到 ¥50 以下（CPL ≤ ¥3.5，只可能来自自然内容或极窄长尾）② 或 LTV 做到 ¥350+（B 端机构版 ¥1,980/年 × 5 家） | — | 才成立 |

**一句话**：这款产品的投放不是"优化出价"能救的，是**要么把客单结构改掉，要么把获客交给内容**。

### 4.5 如果将来投放成立，账户结构照这个建

### 4.6 素材矩阵（24 条，够跑两周）

| 角度 \ 钩子 | 7 秒/数字 | 反常识 | 结果前置 |
| :--- | :--- | :--- | :--- |
| **省时**（不用重写） | 7 秒版 | "别改简历，改词" | "5 分钟出清单" |
| **省钱**（对比代写 ¥300） | 300 vs 19 | "代写不如对齐" | "省下 280" |
| **身份**（社招/转行/应届） | "3 年经验也踩这个坑" | "HR 不会告诉你的" | "他 6 周拿到 offer" |
| **恐惧**（继续海投的代价） | "第 50 份还是没回音" | "海投是最贵的策略" | "30 天后他停了海投" |

× 2 版式（竖版口播 / 对比图文）= 24 条。**先测角度，再测钩子，最后测版式**，一次只改一个变量。

### 4.7 止损规则（照抄，别商量）

| 信号 | 阈值 | 动作 |
| :--- | :--- | :--- |
| 曝光过 3000 仍无点击 | CTR < 0.8% | 换素材角度，别改出价 |
| 有点击无注册 | CVR < 2% | 查落地页首屏（不是加预算） |
| CPA 超标 | > ¥34（1.3×）连续 3 天 | 停该 AdGroup |
| 表现好 | CPA < ¥21 连续 3 天 | 每次放量 ≤ 30% |
| 单素材消耗 | > ¥78（3×CPA）无转化 | 判死，立即替换 |

### 4.8 归因（求职产品必须换口径）

- **UTM 三层**：`utm_source=xhs & utm_medium=note & utm_campaign=jdgap & utm_content=angle_time`
- **服务端回传**：注册、完成首份匹配报告、付费三个事件，同一 `user_id` 对齐。
- **主口径不是注册，是"完成首份报告"**：求职产品注册成本极低（填个邮箱就行），拿注册考核必然自嗨。
- **增量验证**：有预算时做城市/渠道 holdout；没有预算时用"同一内容发 vs 不发"的对照周。

### 4.9 合规红线（这行比别的行业严）

- **不得承诺"保 offer / 保面试 / 100% 通过"**（广告法 + 平台规则，直接封号）。
- 简历属**敏感个人信息**：需明示同意、可一键删除、不得用于模型训练、不得对外提供。
- 不得使用真实 HR / 企业 Logo 做背书暗示。

## 8. 这份总案最想让你记住的三件事

1. **顺序不能倒**：先算 LTV 与 CAC 上限（营销），才谈渠道（推广），最后才谈出价（投放）。倒着来，就是花最贵的钱验证最不确定的假设。
2. **策划是杠杆，不是装饰**：￥0 预算下，唯一能改变 CPA 的变量是"素材与选题"，也就是策划。24 条素材矩阵不是给投手用的，是给"没有预算的人"用的。
3. **算出来不能投，是结论，不是失败**：把"投放不成立"写进总案，比花三个月烧钱后才发现要值钱得多。要改的是客单结构（upsell / B 端），不是出价技巧。
