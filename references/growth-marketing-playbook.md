# 营销策划、推广与投放实战手册 (Growth & Marketing Playbook)

> **一句话**：营销不是"上线后发几条推文、投几百块广告试试"，而是把 **「谁买 / 为什么买 / 从哪来 / 花多少钱 / 怎么算清账」** 这五个问题，在写代码之前就答完。
> 本手册对应【商运增长与数据军团】（CMO / Growth / COO / BI），是阶段 0、1、6 的必读件。

---

## 0. 这一块为什么会空转（三张空头支票）

规划里最常见的三句废话，每一句都对应一个缺失的判据：

| 空话 | 缺的东西 | 补法 |
| :--- | :--- | :--- |
| "我们会做小红书 / 抖音 / Product Hunt" | 渠道与产品的匹配判据 | 用第 2.1 节的斗牛犬框架，先选 3 个测试、只留 1 个主渠道 |
| "先投点广告看看效果" | CAC 上限与止损线 | 用第 3.1 节先算三条线，再开账户 |
| "靠内容引流，做 SEO" | 选题矩阵与转化路径 | 用第 1.5 节内容矩阵 + 第 2.4 节 UTM 落地页一一对应 |

**三条铁律**：

1. **没有目标 CPA 的投放，等于烧钱做用户调研**；
2. **没有转化路径的渠道，只是给自己刷存在感**；
3. **没有归因方案的增长，月底永远说不清哪笔钱有用**。

## 1. 营销策划（Marketing Strategy）：先把话说对，再谈去哪说

### 1.1 定位四件套（缺一件，文案就会写成自嗨）

| 要素 | 要回答的问题 | 反面案例 |
| :--- | :--- | :--- |
| **ICP（理想客户画像）** | 谁？什么规模？什么角色？现在用什么替代方案？ | "面向所有需要效率的人" |
| **JTBD 场景** | 他在什么时刻、为了完成什么任务来找你？ | "提升生产力" |
| **替代方案** | 不用你，他现在怎么办（Excel / 人工 / 竞品 / 忍着）？ | 假装没有竞品 |
| **唯一差异** | 只有你能做到的那一件事，能否一句话说清？ | "功能更全、体验更好、更快" |

**定位陈述模板**（填空即可，不要形容词堆砌）：

> 为【ICP】在【具体场景】下解决【可量化的痛点】，不同于【替代方案】，我们【唯一差异】，并且【一句证据】。

### 1.2 价值主张的三层结构

1. **电梯稿（10 秒）**：一句话说清"给谁、解决什么、凭什么"。
2. **三个 Proof（30 秒）**：数据、客户、演示，各一个；没有就写"测试数据 + 早期客户反馈"，别编。
3. **反对意见处理（3 分钟）**：价格贵 / 迁移麻烦 / 数据安全 / 会不会跑路 —— 每条准备一句正面回答。

### 1.3 定价的营销面（与 `economics-formulas.md` 配套读）

- **锚点**：三档定价中，中间档必须是"最想卖的那档"，用最高档把它衬得划算。
- **命名**：Hobby / Pro / Team，或按使用量命名（如"起步版/增长版/规模化"），不要用"基础版/高级版/旗舰版"这种无信息量词。
- **年付折扣**：15%~20% 是常见区间，本质是用折扣换现金流与留存。
- **免费层**：必须有水印 + 硬限流，否则你是在给羊毛党做公益。

### 1.4 Landing Page 的九段结构与每段要回答的疑问

| 段落 | 内容 | 读者心里的问题 |
| :--- | :--- | :--- |
| 1 Hero | 一句话价值 + 主 CTA | "这是干什么的？" |
| 2 痛点镜像 | 3 条具体场景（不是形容词） | "你懂我吗？" |
| 3 解决方案 | 3 步怎么用 | "怎么用？" |
| 4 差异对比 | 与替代方案的一行行对比 | "凭什么是你？" |
| 5 证据 | 数据 / 客户 / 演示视频 | "真的有用吗？" |
| 6 定价 | 三档 + 一句"为什么这个价" | "多少钱？" |
| 7 风险逆转 | 退款 / 免费试用 / 数据可导出 | "万一不行呢？" |
| 8 FAQ | 6 个真实反对意见 | "还有别的问题吗？" |
| 9 尾部 CTA | 与 Hero 同文案 | "现在做什么？" |

> **验收标准**：把页面发给 5 个目标用户，让他们说出"这是给谁用的、解决什么"，5 人里 3 人说不出来 = 重写。

### 1.5 内容矩阵（4 类内容 × 3 种形态）

| 内容类型 | 作用 | 举例 | 转化位 |
| :--- | :--- | :--- | :--- |
| **痛点教育** | 拉新，扩大认知 | "为什么你的周报要写 2 小时" | 文末工具清单 / 模板下载 |
| **对比选型** | 截流，抢决策 | "X vs Y vs 我们：三种方案的真实成本" | 对比表 + 试用 |
| **使用教学** | 激活，降低门槛 | "10 分钟做出第一版" | 模板 + 新手任务 |
| **客户证据** | 临门一脚 | 客户复盘、前后对比 | 案例页 + demo 预约 |

形态：图文（小红书/公众号）、短视频（抖音/B站/视频号）、结构化页面（SEO 落地页）。

### 1.6 上市节奏（T-30 → T+30）

| 时间 | 动作 | 交付物 |
| :--- | :--- | :--- |
| T-30 | 锁定 ICP 与一句话价值，做假门把手页 | 落地页 + 等候名单 |
| T-14 | 备齐 3 条素材（痛点/对比/演示），联系 10 个种子用户 | 素材库 + 种子名单 |
| T-7 | 目录站与社区预热（PH 即将上线、Reddit/即刻 预告） | 预热帖 |
| T-0 | 集中发布（一天内打完所有渠道） | 发布包：文案 3 版 + 图 3 张 + 视频 1 条 |
| T+7 | 复盘数据，砍掉无效渠道，加码有效素材 | 首周复盘表 |
| T+30 | 定主渠道 + 定投放预算，进入常态 | 增长方案定稿 |

## 2. 推广（Organic Growth）：渠道不是越多越好

### 2.1 斗牛犬框架（Bullseye Framework）：19 个渠道 → 3 个测试 → 1 个主渠道

**第一步：把 19 个渠道全列出来，逐个打分（可行性 / 成本 / 与 ICP 匹配度 / 可追踪性，1~5 分）。**

| # | 渠道 | # | 渠道 | # | 渠道 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | SEO / 内容站 | 8 | 邮件营销 | 15 | 线下活动 / 展会 |
| 2 | 应用商店 / 插件市场 | 9 | 联盟 / 分销 | 16 | 冷邮件（Cold Email） |
| 3 | 社区（Reddit/即刻/V2EX/小红书） | 10 | 现有平台寄生（寄生流量） | 17 | 播客 / 直播 |
| 4 | 目录站（PH / AlternativeTo / G2） | 11 | 线下地推 | 18 | 达人 / KOL 合作 |
| 5 | 付费投放（搜索/信息流） | 12 | 推荐 / 裂变 | 19 | 换量 / 互推 |
| 6 | 社交账号运营 | 13 | 公关 / 媒体 | | |
| 7 | 开发者关系（开源/API 文档） | 14 | 商务拓展（BD） | | |

**第二步：只挑 3 个做 2~4 周的低成本测试，每个渠道必须有独立 UTM 与独立落地页。**
**第三步：留下唯一一个「CAC 最低 + 可复制 + 不依赖个人英雄」的主渠道，其余降级为辅助。**

> **判定标准**：主渠道必须同时满足 ① 单客成本低于目标 CAC 的 70%；② 放量 3 倍后成本不崩；③ 流程可写成 SOP 交给别人执行。

### 2.2 渠道-产品匹配判据（先看这张表，别凭感觉选）

| 产品类型 | 首选渠道 | 次选 | 明确不划算 |
| :--- | :--- | :--- | :--- |
| 开发者工具 / API | 开源 + 文档 SEO + HN/Reddit + 目录站 | 冷邮件 BD | 抖音信息流（人群错配） |
| 内容 / 创作工具 | 小红书 + 抖音 + 模板页 SEO | 达人分销 | 冷邮件 |
| B2B SaaS（中小企业） | 搜索广告（高意图词）+ 对比页 SEO | 冷邮件 + 展会 | 泛信息流 |
| 企业内部工具 | BD + 行业社群 + 私有化案例 | 展会 | C 端社交平台 |
| 电商 / 消费品 | 千川/聚光 + 达人 + 私域 | 搜索广告 | 纯品牌广告（早期烧不起） |

### 2.3 冷启动三板斧的 SOP

**A. 社区（找"已经在讨论这个问题"的人，不是发广告）**

1. 选 3 个 ICP 聚集的社区（如 Reddit 子版、即刻圈子、V2EX 版块、小红书话题）；
2. 先做 2 周"只回答问题、不提产品"的账号铺垫；
3. 发一篇"我们怎么解决 X 问题（附方法与数据）"，产品只在结尾出现一次；
4. 评论区逐条回复，把高频疑问沉淀进 FAQ 与 Landing Page。

**B. 目录站（一次性动作，长期拿被动流量）**

- Product Hunt（英文市场）、AlternativeTo、G2/Capterra（B2B）、国内的小众软件站与导航站；
- 三件套：一句价值 + 3 张图 + 一条 30 秒演示；发布当天安排 10~20 个真实用户留言（不要买假评论，会被清）。

**C. 内容 SEO（唯一能复利的渠道）**

- 三类页面最容易起量：`vs 竞品对比页`、`场景模板页`（"XX 模板免费下载"）、`教程页`（"如何做 XX"）；
- 每页一个主关键词 + 一个转化位；新站前 3 个月别指望排名，先攒 20~30 篇。

### 2.4 内容到转化的路径（每个渠道一条独立链路）

```text
渠道内容 → 专属 UTM 链接 → 专属落地页（同一套话术） → 单一 CTA（注册/领模板/加微信）
        → 事件埋点（view / signup / activate / pay） → 7 日后归因回看
```

> 一个渠道配一个落地页，是"能算账"的最低要求。全都指向首页 = 永远不知道钱花在哪有效。

### 2.5 达人与素人铺量

- 报价判定：粉丝单价（CPM）反推 —— 报价 / 预期曝光 ≤ 目标 CPM 的 1.5 倍才谈；
- 只投**能挂追踪链接或专属码**的，纯品牌曝光留给有预算的阶段；
- 素人铺量（小红书/抖音）适合信任型品类，必须给统一 Brief（3 个必讲点 + 3 个禁讲点），否则内容会跑偏。

## 3. 投放（Paid Acquisition）：先算账，再开账户

### 3.1 开账户前必须算清的三条线

| 线 | 公式 | 含义 | 用法 |
| :--- | :--- | :--- | :--- |
| **目标 CPA 上限** | `LTV × 毛利率 × 可接受回本系数` | 最多能花多少钱买一个付费用户 | 超过即止损 |
| **最低 ROAS** | `1 / 毛利率`（如毛利率 80% → ROAS ≥ 1.25） | 不亏钱的底线 | 低于即调素材/调价 |
| **日预算与学习期** | 单广告组日预算 ≥ `3 × 目标 CPA` | 让平台有足够样本学习 | 预算太碎 = 永远学不出来 |

### 3.2 账户结构（可直接照抄的命名规范）

```text
Campaign:  {市场}-{目标}-{品类}        例：CN-注册-AI写作
AdSet/单元: {渠道位}-{人群}-{出价}      例：信息流-兴趣-OCPM
Creative:   {角度}-{钩子}-{版式}-{版本}  例：痛点-省钱-竖版-v3
```

原则：**一个 Campaign 只验证一个假设**；一个 AdSet 只跑一种人群+一种出价；素材按"角度→钩子→版式"三级命名，否则复盘时你分不清是哪个变量赢了。

### 3.3 素材测试矩阵（一轮 24 条，够跑两周）

| 维度 | 取值（示例） | 组合方式 |
| :--- | :--- | :--- |
| **角度（4）** | 省钱 / 省时 / 身份认同 / 恐惧损失 | 4 角度 × 3 钩子 = 12 条 |
| **钩子（3）** | 数字冲击（"3 分钟"）/ 反常识（"别再手动…"）/ 结果前置（"从 0 到 1 万粉"） | 每条配 2 版式 = 24 条 |
| **版式（2）** | 竖版口播 / 图文对比 | |

规则：**先测角度，再测钩子，最后测版式**。一次改三个变量，赢了也不知道为什么赢。

### 3.4 冷启动判定与放量 / 止损规则

> 下列数值是**经验起点**，不是行业标准；必须用你自己的历史数据校准后再用。

| 信号 | 经验起点 | 动作 |
| :--- | :--- | :--- |
| 曝光已过 3000，仍在挂零 | CTR < 0.8% | 换素材角度，别改出价 |
| 有点击无转化 | CVR < 2% | 查落地页与人群匹配，不要加预算 |
| CPA > 1.3 × 目标 | 连续 3 天 | 停该 AdSet，保留最优素材迁到新组 |
| CPA < 0.8 × 目标且稳定 3 天 | — | 每次放量 ≤ 30%，避免打断学习期 |
| 单素材消耗 > 3 × 目标 CPA 仍未转化 | — | 判定素材死亡，立即替换 |
| ROAS < 最低线但 CPA 达标 | — | 是客单价/转化结构问题，不是投放问题 |

### 3.5 平台差异（选错平台，素材再好也白投）

| 平台 | 适合 | 素材形态 | 常见坑 |
| :--- | :--- | :--- | :--- |
| **Google / Bing 搜索** | 高意图、B2B、工具类 | 文字 + 落地页 | 关键词太泛，烧钱买"逛的人" |
| **Meta（FB/IG）** | 泛人群测试、消费品 | 竖版短视频 + 图文 | 兴趣定向过度细分，样本不足 |
| **TikTok** | 年轻人群、内容型产品 | 原生感 UGC 口播 | 硬广直接被划走，完播率低 |
| **巨量千川（抖音电商）** | 带货、客单 < 300 | 口播 + 场景演示 | 只投成交，不看退款率 → 假 GMV |
| **小红书聚光** | 女性/生活方式/创作工具 | 图文笔记 + 素人感 | 笔记质量决定成本，投手救不了烂内容 |
| **腾讯广告（微信）** | 私域承接、中高客单 | 图文 + 落地页 | 落地页跳转链路长，转化流失 |
| **知乎 / B站** | 决策周期长、技术型 | 长图文 / 中长视频 | 起量慢，别用短周期指标考核 |

> **付费投放没有靠谱的开源自建方案**：平台侧算法与竞价数据不对外，自建"投放系统"只能做到素材管理与报表聚合，别把它当核心竞争力（工具见第 5.1 节）。

### 3.6 归因与反作弊

- **last-click 会骗你**：品牌词搜索会抢走自然口碑的功劳；内容渠道的实际贡献被低估。
- **最低配置**：UTM（渠道/素材/版位三层）+ 服务端事件回传 + 落地页首屏埋点，三者对齐同一 `user_id`。
- **增量验证**：有预算时做 geo holdout（选两个相似城市，一个投一个不投，比新增量），比任何归因模型都硬。
- **刷量识别**：曝光涨而停留时长不涨、注册集中在同一时段/同一设备指纹、转化后 7 日留存极低 —— 三者同时出现，基本可判定异常流量。

## 4. 指标字典（口径不统一，月底必然吵架）

| 指标 | 公式 | 看什么 | 危险信号 |
| :--- | :--- | :--- | :--- |
| CPM | 花费 / 曝光 × 1000 | 流量贵不贵 | 同类素材间波动 > 50% |
| CTR | 点击 / 曝光 | 素材吸引力 | < 0.8%（信息流） |
| CVR | 转化 / 点击（或访问） | 落地页与人群匹配 | < 2%（注册类） |
| CPA | 花费 / 转化数 | 买人成本 | > 1.3 × 目标 |
| ROAS | 收入 / 花费 | 投放是否亏 | < 1 / 毛利率 |
| CAC | (营销费 + 销售成本) / 新增付费 | 全口径获客成本 | > LTV / 3 |
| Payback | CAC / (ARPU × 毛利率) | 多久回本 | > 12 个月 |
| 激活率 | 完成关键动作 / 注册 | 产品是否接得住流量 | < 40%（工具类） |
| D7 / D30 留存 | 第 7/30 日仍活跃 / 首日用户 | 是否真需求 | D7 < 20% |
| NPS | 推荐者% − 贬损者% | 口碑势能 | < 30 |

> 与 `economics-formulas.md` 的分工：那边算"能不能活"（LTV/CAC/COGS），这边算"钱花得值不值"（CPA/ROAS/留存）。

### 5.2 公开增长打法案例（只借机制，不抄数字）

> 以下为公开流传的经典案例，仅做**机制拆解**；不含本项目实测数据，也不要照搬其体量前提。

| 案例 | 做法 | 可迁移的机制 | 不要照抄的地方 |
| :--- | :--- | :--- | :--- |
| **Dropbox** | 双面推荐：邀请双方都得存储空间 | 把"推荐"做成产品内动作，双向激励 | 你如果没有天然可赠送的额度（存储/次数），激励会变成纯现金成本 |
| **Airbnb 早期** | 借 Craigslist 已有流量做交叉发布 | 寄生已有流量池，比自己造池快 10 倍 | 平台一旦封禁即归零；只能当冷启动跳板，不能当主渠道 |
| **Notion** | 模板 + 社区，用户产出的模板页自带搜索流量 | 用户生成资产 = 分发资产（UGC 即 SEO） | 前提是产品本身"可被展示"；纯后台工具没有可展示物 |
| **Superhuman** | 邀请制 + 1:1 上手辅导 | 稀缺感 + 高触达 onboarding，把激活率做穿 | 需要人力密集交付，规模不经济，只适合高客单 |
| **Figma** | 社区文件与插件生态带动设计团队内部扩散 | 供给侧内容拉动需求侧，天然病毒式组内传播 | 需要开放的平台能力，否则生态起不来 |
| **Product Hunt 发布** | 单日集中所有渠道打一次 | 把注意力压缩成峰值，短期获取密集曝光 | 一次性事件，复购型 B2B 的第二增长曲线不在这里 |
| **HubSpot 入站营销** | 长期内容矩阵 + 免费工具引流 | 内容资产复利，越老越值钱 | 需要 12~24 个月才见效，现金流撑不住就别学 |

### 5.3 反例（最常见的四种死法）

1. **渠道错配**：开发者工具去投抖音信息流，点击便宜但全是无效人群，CPA 高得离谱。
2. **素材疲劳**：同一素材跑满两周不换，CTR 腰斩还加大预算，等于加速烧钱。
3. **归因自嗨**：只报 last-click，把自然口碑的功劳记在品牌词广告上，越投越"有效"。
4. **折扣换来的假 PMF**：靠大额折扣冲到一批用户，D7 留存 10%，却对外宣称"验证了需求"。

### 6.2 《投放测算与止损表》（示例数字仅示范口径）

| 项目 | 值 | 说明 |
| :--- | :--- | :--- |
| ARPU（月） | ¥99 | 示例 |
| 毛利率 | 80% | 扣掉算力与支付通道 |
| 月流失率 | 5% | → LTV ≈ ¥1,584 |
| 目标 CAC | ≤ ¥300 | LTV/CAC ≈ 5.3，健康区间 |
| 最低 ROAS | 1.25 | 1 / 毛利率 |
| 目标 CPL（注册） | ¥30 | 假设注册→付费转化 25%，则付费 CPA = 30 / 0.25 = ¥120 |
| 目标 CPA（付费） | ¥120 | ≤ 目标 CAC，留出安全垫 |
| 单广告组日预算 | ≥ ¥360 | 3 × 目标 CPA |
| 止损规则 | CPA > ¥156 连续 3 天停 | 1.3 × 目标 CPA |

> **注意**：注册成本（CPL）与付费成本（CPA）不是一回事，务必用"注册→付费转化率"回算，别拿 CPL 自我安慰。

### 6.3 上线前 20 项检查（营销侧）

1. 一句话价值能被 5 个目标用户复述；2. 每个渠道有独立 UTM；3. 每个渠道有独立落地页；4. 落地页有唯一 CTA；5. 埋点覆盖 view/signup/activate/pay；6. 支付链路跑通（含退款）；7. 定价三档且锚点清晰；8. 有 3 条素材（痛点/对比/演示）；9. 素材按命名规范归档；10. 有目标 CPA 与止损线；11. 有归因方案（UTM + 服务端事件）；12. 有 7 日留存基线；13. 有私域/客服承接入口；14. 社区账号已养 2 周；15. 目录站素材备齐；16. 发布日排期到小时；17. 有舆情/差评监控词；18. 有退款与投诉 SOP；19. 有周复盘模板；20. 有"停投"决策人（不能是投手自己说了算）。
