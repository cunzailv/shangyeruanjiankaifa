# 营销、策划、推广、投放：四层增长体系 (The Four-Layer Growth System)

> **一句话**：**营销管全局，策划出主意，推广造声量，投放买曝光。**
> 四件事、四套 KPI、四种资源（决策 / 创意 / 时间 / 现金）。混成一个词，就一定会互相甩锅：声量不行怪投放，转化不行怪策划，预算不清怪营销。

---

## 0. 四层体系：一张表先分清

| 层 | 一句话职责 | 它回答的问题 | 核心产出 | 主 KPI | 花的是什么 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **① 营销 (Marketing)** | **管全局** | 卖给谁、卖什么、卖多少钱、走哪条路、怎么衡量 | 增长总案（定位 + 定价 + 渠道战略 + 预算 + 指标） | LTV:CAC、增速、渠道结构健康度 | 决策与预算分配权 |
| **② 策划 (Planning / Creative)** | **出主意** | 这一波说什么、怎么说、用什么形式、靠什么被记住 | Big Idea、Campaign 概念、Creative Brief、内容与素材脚本 | 3 秒记忆率、内容互动率、素材胜出率 | 创意与人力 |
| **③ 推广 (Promotion)** | **造声量** | 怎么用不花钱的方式让人知道、讨论、主动搜 | 自有阵地 + 内容资产 + 社区口碑 + 媒体报道 | 品牌搜索量、自然注册、外部提及、分享率 | 时间与关系 |
| **④ 投放 (Paid Media)** | **买曝光** | 花多少钱、买多少曝光、买回来的人划不划算 | 账户结构 + 素材矩阵 + 止损规则 + 归因报告 | CPM / CTR / CPA / ROAS | **现金** |

```text
① 营销：定方向、定价、定渠道、分预算（管全局的大脑）
        ↓ 下发"这一波要说什么、给谁看"
② 策划：把方向变成可传播的内容与素材（造子弹）
        ↓ 交付内容与脚本
③ 推广：用自有与赢得渠道把子弹打出去，造声量（放大的免费部分）
④ 投放：用现金买确定性曝光，把声量补成规模（付费的加速器）
        ↓ 数据回流（UTM / 埋点 / 归因）
① 营销：按真实 CAC 与留存，重新分配下一轮预算
```

### 0.1 四个高频混淆（说错一个，方案就会跑偏）

| 错的说法 | 真相 | 后果 |
| :--- | :--- | :--- |
| "营销就是投广告" | 投放只是营销的**最后一个执行手段**；营销决定要不要投、投多少、投给谁 | 一上来就烧钱，没有定位也没有落地页 |
| "策划就是写文案" | 文案是策划的**产物之一**；策划先定 Big Idea 与单一信息，再落文字 | 文案很漂亮，但十条文案说了十件事 |
| "推广就是发帖" | 发帖只是**动作**；推广的本质是积累可复用的注意力资产（内容/社区/口碑） | 每天发，发完就沉，账号永远起不来 |
| "投放能替代推广" | 投放买的是**曝光**，买不到信任与口碑；停投即归零 | 一停投，新增归零，误判"产品没需求" |

### 0.2 资源配比（经验起点，按阶段调整，不是行业标准）

| 阶段 | ① 营销（决策） | ② 策划（创意） | ③ 推广（人力/时间） | ④ 投放（现金） |
| :--- | :--- | :--- | :--- | :--- |
| **0 → 1 验证期** | 精力 30% | 精力 30% | **精力 60%** | **≤ 10% 预算（只做小额验证）** |
| **1 → 10 增长期** | 精力 20% | 精力 20% | 精力 30% | **预算 50%** |
| **10 → 100 规模化** | 精力 15% | 精力 15% | 精力 25% | **预算 60%** |

**顺序铁律**：营销定盘 → 策划出弹 → 推广放大 → 投放买量。倒过来做（先投放）＝ 用最贵的钱验证最不确定的假设。

### 0.3 四层各自"失灵"的症状（用来定位到底哪一层坏了）

| 层 | 失灵症状 | 先修什么 |
| :--- | :--- | :--- |
| 营销 | 每个渠道都在做，但没人说得清"我们靠什么增长"；预算按心情分；指标互相打架 | 重写定位与增长模型，砍掉与 ICP 不匹配的渠道 |
| 策划 | 内容数量不少，但没有一句能被记住；换个产品名也能用（可替换性极高） | 补 Big Idea 与单一信息，砍掉功能堆砌 |
| 推广 | 发出去没人互动；社区账号被当广告位；只发不养；SEO 三个月没动静就放弃 | 先养号 2 周 + 换选题（不是加投放） |
| 投放 | 有曝光没转化；同一素材两周不换；只看 CPA 不看 D7 留存 | 查落地页与人群，先止损再谈放量 |

## 1. 营销：管全局（Marketing as the System）

营销不产出内容，也不操作广告后台。它产出**决策**：卖给谁、卖什么、多少钱、走哪条路、钱怎么分、怎么算赢。

### 1.1 营销必须回答的六个问题

| # | 问题 | 答不出来会怎样 |
| :--- | :--- | :--- |
| 1 | 市场与人群是谁（ICP） | 渠道全选错，素材全自嗨 |
| 2 | 他现在的替代方案是什么 | 价值主张没有参照系，显得"可有可无" |
| 3 | 我们的唯一差异（一句话） | 只能卷价格 |
| 4 | 收多少钱、怎么收（定价三档） | LTV 算不出来，CAC 上限也就没有 |
| 5 | 主要靠哪条增长路径（PLG / 内容 / 销售 / 私域） | 四层资源配比全凭感觉 |
| 6 | 用什么指标判断成败（不是"感觉有用"） | 月底复盘永远在吵架 |

### 1.2 定位四件套

| 要素 | 要求 | 反面案例 |
| :--- | :--- | :--- |
| **ICP** | 谁、什么规模、什么角色、现在用什么 | "面向所有需要效率的人" |
| **JTBD 场景** | 在什么时刻、为了完成什么任务来找你 | "提升生产力" |
| **替代方案** | 不用你，他怎么办（Excel / 人工 / 竞品 / 忍着） | 假装没有竞品 |
| **唯一差异** | 只有你能做到的那一件事，一句话说清 | "功能更全、体验更好、更快" |

**定位陈述模板**：为【ICP】在【具体场景】下解决【可量化痛点】，不同于【替代方案】，我们【唯一差异】，并且【一句证据】。

### 1.3 价值主张三层

1. **电梯稿（10 秒）**：给谁、解决什么、凭什么。
2. **三个 Proof（30 秒）**：数据 / 客户 / 演示，各一个；没有就写测试数据 + 早期反馈，别编。
3. **反对意见（3 分钟）**：贵 / 迁移麻烦 / 数据安全 / 会不会跑路，各一句正面回答。

### 1.4 定价的营销面（与 `economics-formulas.md` 配套读）

- **锚点**：三档里中间档是"最想卖的那档"，用最高档把它衬得划算。
- **命名**：Hobby / Pro / Team，或"起步版 / 增长版 / 规模化"；不要"基础版 / 高级版 / 旗舰版"。
- **年付折扣**：15%~20% 是常见区间，本质用折扣换现金流与留存。
- **免费层**：必须有水印 + 硬限流，否则是在给羊毛党做公益。

### 1.5 渠道战略：决定"推广与投放各拿多少"

| 增长模型 | 特征 | 推广 / 投放 配比建议 |
| :--- | :--- | :--- |
| **内容驱动（SEO / 社区）** | 起效慢、可复利、护城河深 | 推广 70% / 投放 30% |
| **产品驱动（PLG / 裂变）** | 靠产品内置传播，边际成本低 | 推广 60% / 投放 40%（投放在"加速"而非"获客"） |
| **销售驱动（SLG / BD）** | 高客单、决策链长 | 推广 40% / 投放 20% / 销售 40% |
| **私域驱动（社群 / 复购）** | 靠承接与复购赚钱 | 推广 50% / 投放 30% / 私域运营 20% |

### 1.6 营销的产出物：《增长总案》（模板见 §7.1）

必须包含：定位四件套、价值主张、定价三档、增长模型、渠道预算、目标数字（CAC / ROAS / 回本周期）、复盘节奏。**没有目标数字的总案 = 没有总案。**

## 2. 策划：出主意（Creative & Campaign Planning）

策划是"把营销的方向翻译成能被人记住、愿意传播的东西"。它不负责投放，也不负责选渠道。

### 2.1 策划的三种活（别混着干）

| 类型 | 周期 | 产出 | 判定标准 |
| :--- | :--- | :--- | :--- |
| **Campaign 大创意** | 一次活动 / 一个季度 | Big Idea + 主视觉 + 传播钩子 | 能不能被一句话复述 |
| **常规内容** | 每周持续 | 选题 + 文案 + 图文/视频 | 有没有明确单一信息与转化位 |
| **素材脚本** | 配合投放 | 15s / 30s 口播脚本、图文版式 | 3 秒能否抓住人 |

### 2.2 Big Idea 的四个检验（全过才算成立）

1. **一句话说得清**：不带产品名也能讲明白。
2. **演得出来**：有画面、有动作，不是抽象形容词。
3. **记得住**：听完能复述，且只记住一个点。
4. **能落到 CTA**：知道下一步干什么（注册 / 领模板 / 预约演示）。

### 2.3 Campaign 概念公式：洞察 → 冲突 → 反转 → 行动

| 要素 | 要回答 | 示例方向（示意，非成品） |
| :--- | :--- | :--- |
| **洞察** | 用户真实但没说出口的事实 | "周报不是写不出来，是不敢写短" |
| **冲突** | 他想要的 vs 现实阻碍 | 想被看见专业度，但时间只够糊弄 |
| **反转** | 你的产品如何破局 | 把"写"变成"选 + 改" |
| **行动** | 一个具体动作 | "上传上周记录，3 分钟出初稿" |

### 2.4 Creative Brief（一页纸，不写满这 9 项就不要开工）

```markdown
1. 背景：为什么现在做这一波
2. 目标：单一目标（认知 / 留资 / 转化，三选一）
3. 受众：ICP + 他此刻的处境
4. 单一信息：只能有一条，超过一条即失败
5. 支持点：三个 Proof
6. 调性：三个形容词 + 三个禁讲点
7. 必含元素：Logo / 水印 / 二维码 / 免责声明
8. 形式与规格：图文 3:4、视频 9:16、落地页
9. 成功标准：3 秒记忆率 / 互动率 / 转化率的哪一个
```

### 2.5 内容选题库：4 类 × 3 形态

| 内容类型 | 作用 | 举例 | 转化位 |
| :--- | :--- | :--- | :--- |
| **痛点教育** | 拉新、扩大认知 | "为什么你的周报要写 2 小时" | 模板下载 / 工具清单 |
| **对比选型** | 截流、抢决策 | "X vs Y vs 我们：三种方案的真实成本" | 对比表 + 试用 |
| **使用教学** | 激活、降门槛 | "10 分钟做出第一版" | 新手任务 |
| **客户证据** | 临门一脚 | 客户复盘、前后对比 | 案例页 / 预约演示 |

形态：图文（小红书 / 公众号）、短视频（抖音 / B站 / 视频号）、结构化页面（SEO 落地页）。

### 2.6 十个可复用的钩子（写标题时直接套）

1. 数字冲击（"3 分钟"）；2. 反常识（"别再手动…"）；3. 结果前置（"从 0 到 1 万粉"）；4. 损失厌恶（"你正在浪费的 4 小时"）；5. 身份标签（"给独立开发者的…"）；6. 强对比（"同行都在用，你还在…"）；7. 悬念（"我们试了 12 种方法，只有 1 个有效"）；8. 权威/证据（"实测 30 天数据"）；9. 场景代入（"周五下午 6 点，老板要周报"）；10. 时间压力（"这周内免费"）。

### 2.7 文案的五个层级

| 层级 | 长度 | 任务 |
| :--- | :--- | :--- |
| 口号 | ≤ 6 字 | 被记住 |
| 主标题 | ≤ 12 字 | 说清价值 |
| 副标题 | ≤ 30 字 | 补足"给谁 + 凭什么" |
| 正文 | 3 段 | 痛点 → 方案 → 证据 |
| CTA | 1 个动词 | 明确下一步 |

### 2.8 视觉锤与一致性

- **一个固定色**（主色 ≤ 2 个）、**一个固定构图**（左文右图 / 居中大字）、**一个固定元素**（水印 / 角标 / 吉祥物）。
- 一致性优先于好看：用户是靠"第三次看到同样的东西"才记住你的，不是靠单张惊艳。

### 2.9 创意评审：什么算过关

| 标准 | 不合格的样子 |
| :--- | :--- |
| 3 秒能懂 | 需要读完三行字才明白 |
| 只有一条信息 | 一条素材讲了 4 个卖点 |
| 有可分享点 | 看完没有任何转发动机 |
| 与定位一致 | 这条内容和你的 ICP 完全无关，只是蹭热点 |
| 有明确 CTA | 看完不知道下一步做什么 |

> **产量经验值**：每周 ≥ 3 条内容 + 2 条投放素材脚本。策划的产能不足，投放就没有弹药，推广也没有话题。

### 2.10 策划的四种死法

1. **功能堆砌**：一条素材列 8 个功能，用户一个也没记住。
2. **自嗨创意**：团队觉得绝妙，目标用户看不懂（评审时找 3 个真实用户投票）。
3. **模仿不到骨**：抄了人家的形式，没抄到人家的洞察，效果差 10 倍。
4. **没有可分享点**：内容只能"看"，不能"传"，推广阶段无米下锅。

## 3. 推广：造声量（Promotion / Organic）

推广的本质：**不直接用现金买曝光，而是用内容、关系与社区换注意力，并把它沉淀成可复用资产。**

### 3.1 三种可积累的资产

| 类型 | 含义 | 例子 | 特点 |
| :--- | :--- | :--- | :--- |
| **自有（Owned）** | 你自己控制的阵地 | 官网、公众号、社群、邮件列表 | 可反复触达，边际成本趋零 |
| **赢得（Earned）** | 别人主动给你的曝光 | 媒体报道、用户口碑、被引用、被推荐 | 可信度最高，但不可控 |
| **寄生（Borrowed）** | 借别人已有流量池 | 平台社区、目录站、达人社群 | 起量快，随时可能被封 |

> 只做"寄生"= 永远在别人的地基上盖楼；只做"自有"= 起量太慢。**健康结构是：寄生起量 → 导流自有 → 赢得背书。**

### 3.2 斗牛犬框架：19 渠道 → 3 个测试 → 1 个主渠道

| # | 渠道 | # | 渠道 | # | 渠道 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | SEO / 内容站 | 8 | 邮件营销 | 15 | 线下活动 / 展会 |
| 2 | 应用商店 / 插件市场 | 9 | 联盟 / 分销 | 16 | 冷邮件（Cold Email） |
| 3 | 社区（Reddit/即刻/V2EX/小红书） | 10 | 平台寄生流量 | 17 | 播客 / 直播 |
| 4 | 目录站（PH / AlternativeTo / G2） | 11 | 线下地推 | 18 | 达人 / KOL |
| 5 | 付费投放（搜索 / 信息流） | 12 | 推荐 / 裂变 | 19 | 换量 / 互推 |
| 6 | 社交账号运营 | 13 | 公关 / 媒体 | | |
| 7 | 开发者关系（开源 / API 文档） | 14 | 商务拓展（BD） | | |

> 注意：第 5 项属于**投放**，不属于推广。把它列进来是为了横向比较"这笔钱该花在推广还是投放"，而不是混着做。

**打分维度**（各 1~5 分）：可行性 / 成本 / 与 ICP 匹配度 / 可追踪性。

### 3.3 渠道-产品匹配判据

| 产品类型 | 首选（推广） | 次选 | 明确不划算 |
| :--- | :--- | :--- | :--- |
| 开发者工具 / API | 开源 + 文档 SEO + HN/Reddit + 目录站 | 冷邮件 BD | 抖音信息流 |
| 内容 / 创作工具 | 小红书 + 抖音 + 模板页 SEO | 达人分销 | 冷邮件 |
| B2B SaaS（中小企业） | 对比页 SEO + 行业社群 | 冷邮件 + 展会 | 泛信息流 |
| 企业内部工具 | 行业社群 + 私有化案例 | 展会 | C 端社交平台 |
| 电商 / 消费品 | 达人 + 私域 + 内容种草 | 搜索广告 | 纯品牌广告（早期烧不起） |

### 3.4 冷启动三板斧 SOP

**A. 社区（找"已经在讨论这个问题"的人，不是发广告）**
1. 选 3 个 ICP 聚集的社区；2. 先做 2 周"只回答问题、不提产品"的账号铺垫；3. 发一篇"我们怎么解决 X（附方法与数据）"，产品只在结尾出现一次；4. 把评论区高频疑问沉淀进 FAQ 与落地页。

**B. 目录站（一次性动作，长期被动流量）**
Product Hunt、AlternativeTo、G2/Capterra、国内软件导航站。三件套：一句话价值 + 3 张图 + 30 秒演示；发布日安排 10~20 个真实用户留言（不要买假评论，会被清）。

**C. 内容 SEO（唯一能复利的渠道）**
三类页面最容易起量：`vs 竞品对比页`、`场景模板页`、`教程页`。每页一个主关键词 + 一个转化位。**新站前 3 个月别指望排名**，先攒 20~30 篇。

### 3.5 声量的四个可测信号（否则"声量"永远是玄学）

| 信号 | 怎么测 | 说明 |
| :--- | :--- | :--- |
| 品牌词搜索量 | 搜索后台 / 关键词工具 | 从 0 到有，是最硬的声量指标 |
| 直接访问占比 | 站点统计 | 记不住域名就没有声量 |
| 自然注册来源 | 注册渠道字段 | 排除投放后的真实自然增长 |
| 外部提及数 | 搜品牌名 + 舆情工具 | 被讨论、被引用、被搬运 |

### 3.6 达人 / 素人铺量

- 报价判定：`报价 / 预期曝光` ≤ 目标 CPM 的 1.5 倍才谈；
- 只投**能挂追踪链接或专属码**的，纯曝光留给有预算的阶段；
- 素人铺量必须给统一 Brief（3 个必讲点 + 3 个禁讲点），否则内容跑偏。

### 3.7 推广的节奏与预期管理

| 动作 | 起效周期 | 常见误判 |
| :--- | :--- | :--- |
| 社区养号 + 首发 | 2~4 周 | 发一次没反应就放弃 |
| 目录站发布 | 当天~1 周 | 以为能持续带量（其实一次性） |
| 内容 SEO | 3~6 个月 | 一个月没排名就判"SEO 没用" |
| 媒体报道 | 不可控 | 把 PR 当获客渠道考核 |

### 3.8 中国平台补充表（副业与一人公司最常见的 10 个阵地）

| 平台 | 最适合的变现模型 | 成本特征 | 主要坑 | 判定 |
| :--- | :--- | :--- | :--- | :--- |
| **小红书** | 订阅工具、知识付费、本地服务、求职/教育 | 图文制作成本低，起量快 | 硬广与导流话术限流；私信发码易封 | **首选**（多数 C 端项目主渠道） |
| **抖音** | 内容 IP、带货、短剧 | 起量最快，但泛流量多 | 求职/教育类审核严；硬广即划走 | 只做素材测试，不做主阵地 |
| **视频号** | 私域承接、中高客单 | 依赖社交推荐，成本低 | 冷启动慢，需要公众号/社群导流 | 有私域基础再上 |
| **公众号** | 长文 + 私域、知识付费 | 边际成本近 0 | 打开率持续下滑；断更即掉量 | 做承接，不做拉新主力 |
| **知乎** | 技术型、决策长尾、B 端 | SEO 权重高，寿命长 | 起量慢；广告感强会被限流 | 技术/B 端首选第二渠道 |
| **B 站** | 开发者、长视频、课程 | 制作成本高（脚本+剪辑） | 完播要求高，前 30 秒定生死 | 有视频产能再上 |
| **闲鱼** | 服务履约、代码资产、二手 | 零门槛，交易信任成本低 | 虚拟商品与"代做"类易违规 | 服务型可试，虚拟商品慎入 |
| **知识星球** | 付费社群、专栏 | 抽成低，交付简单 | 依赖 IP 存量；死群会反噬口碑 | 已有 500+ 粉丝再用 |
| **V2EX / 即刻** | 开发者冷启动、工具首发 | 免费，精准 | 反广告文化强，硬推会被踩 | 开发者产品的第一批种子 |
| **1688 / 淘宝** | 电商、货源分销 | 需供应链与资金 | 价格战、退货率 | 非技术杠杆，按需选择 |

**两条硬规则**：① 先定变现模型，再选平台（不是反过来）；② 一个模型最多开 **2 个主平台**，跑满 2 周、算得出单客成本，才允许开第三个。

## 4. 投放：买曝光（Paid Media）

投放的本质：**用现金购买确定性的曝光与可计算的转化。** 它不负责"该不该做营销"，只负责"这笔钱买得值不值"。

### 4.1 开账户前必须算清的三条线

| 线 | 公式 | 含义 | 用法 |
| :--- | :--- | :--- | :--- |
| **目标 CPA 上限** | `LTV × 毛利率 × 可接受回本系数` | 最多能花多少钱买一个付费用户 | 超过即止损 |
| **最低 ROAS** | `1 / 毛利率`（毛利率 80% → ROAS ≥ 1.25） | 不亏钱的底线 | 低于即调素材 / 调价 |
| **日预算与学习期** | 单广告组日预算 ≥ `3 × 目标 CPA` | 让平台有足够样本学习 | 预算太碎 = 永远学不出来 |

### 4.2 账户结构（可直接照抄的命名规范）

```text
Campaign:   {市场}-{目标}-{品类}        例：CN-注册-AI写作
AdSet/单元: {版位}-{人群}-{出价}         例：信息流-兴趣-OCPM
Creative:   {角度}-{钩子}-{版式}-{版本}   例：痛点-省钱-竖版-v3
```

原则：一个 Campaign 只验证一个假设；一个 AdSet 只跑一种人群 + 一种出价；素材三级命名，否则复盘分不清哪个变量赢了。

### 4.3 素材测试矩阵（一轮 24 条，够跑两周）

| 维度 | 取值 | 组合 |
| :--- | :--- | :--- |
| **角度（4）** | 省钱 / 省时 / 身份认同 / 恐惧损失 | 4 × 3 钩子 = 12 条 |
| **钩子（3）** | 数字冲击 / 反常识 / 结果前置 | 每条配 2 版式 = 24 条 |
| **版式（2）** | 竖版口播 / 图文对比 | |

规则：**先测角度，再测钩子，最后测版式**。一次改三个变量，赢了也不知道为什么赢。

### 4.4 冷启动判定与放量 / 止损

> 数值为**经验起点**，必须用你自己的历史数据校准。

| 信号 | 经验起点 | 动作 |
| :--- | :--- | :--- |
| 曝光已过 3000，仍在挂零 | CTR < 0.8% | 换素材角度，别改出价 |
| 有点击无转化 | CVR < 2% | 查落地页与人群匹配，不要加预算 |
| CPA 超标 | > 1.3 × 目标，连续 3 天 | 停该 AdSet，把最优素材迁到新组 |
| CPA 优秀且稳定 3 天 | < 0.8 × 目标 | 每次放量 ≤ 30%，别打断学习期 |
| 单素材消耗 > 3 × 目标 CPA 仍无转化 | — | 判定素材死亡，立即替换 |
| ROAS 低于底线但 CPA 达标 | — | 是客单价 / 转化结构问题，不是投放问题 |

### 4.5 平台差异（选错平台，素材再好也白投）

| 平台 | 适合 | 素材形态 | 常见坑 |
| :--- | :--- | :--- | :--- |
| Google / Bing 搜索 | 高意图、B2B、工具类 | 文字 + 落地页 | 关键词太泛，买来"逛的人" |
| Meta（FB/IG） | 泛人群测试、消费品 | 竖版短视频 + 图文 | 兴趣定向过度细分，样本不足 |
| TikTok | 年轻人群、内容型产品 | 原生感 UGC 口播 | 硬广直接被划走 |
| 巨量千川 | 带货、客单 < 300 | 口播 + 场景演示 | 只看成交不看退款 → 假 GMV |
| 小红书聚光 | 女性 / 生活方式 / 创作工具 | 图文笔记 + 素人感 | 笔记质量决定成本，投手救不了烂内容 |
| 腾讯广告（微信） | 私域承接、中高客单 | 图文 + 落地页 | 跳转链路长，流失高 |
| 知乎 / B站 | 决策周期长、技术型 | 长图文 / 中长视频 | 起量慢，别用短周期指标考核 |

> **付费投放没有靠谱的开源自建方案**：平台算法与竞价数据不对外，自建"投放系统"只能做素材管理与报表聚合，不是核心竞争力（工具见 §6.5）。

### 4.6 出价与预算的四个误区

1. **预算太碎**：单组日预算 < 3 × CPA，平台学不出模型，数据永远难看。
2. **频繁改**：一天调三次出价，等于不断重置学习期。
3. **只看 CPA**：不看 D7 留存，容易买来一批"注册即死"的用户。
4. **把投放当增长本身**：停投归零，说明你买的是流量，不是需求。

### 4.7 归因与反作弊

- **last-click 会骗你**：品牌词搜索会抢走自然口碑的功劳，内容渠道被系统性低估。
- **最低配置**：UTM（渠道 / 素材 / 版位三层）+ 服务端事件回传 + 落地页首屏埋点，三者对齐同一 `user_id`。
- **增量验证**：有预算时做 geo holdout（两个相似城市，一个投一个不投，比新增量），比任何归因模型都硬。
- **刷量识别**：曝光涨而停留时长不涨、注册集中在同一时段 / 同一设备指纹、转化后 7 日留存极低 —— 三者同时出现基本可判定异常。

### 4.8 推广与投放的分工边界（最容易打架的地方）

| 维度 | ③ 推广 | ④ 投放 |
| :--- | :--- | :--- |
| 花的资源 | 人力与时间 | 现金 |
| 曝光确定性 | 不确定，但可积累 | 确定，即时 |
| 边际成本 | 递减（资产复利） | 递增（竞价上涨） |
| 起效周期 | 2 周 ~ 6 个月 | 当天 ~ 3 天 |
| 归因难度 | 难（last-click 会低估） | 相对可算 |
| 适合阶段 | 0→1 验证、长期护城河 | 1→10 放量、确定性增长 |
| 失败信号 | 发了没人看、被社区当广告 | CPA 飙升、素材疲劳 |
| 谁负责 | Growth / 内容运营 | 投手 / 效果营销 |

> **一句话分工**：推广负责"让人愿意来"，投放负责"花钱把人搬过来"。投放的素材必须由策划供弹，落地页必须与推广内容同一套话术。

## 5. 指标字典（按四层分组，口径不统一必然吵架）

| 层 | 指标 | 公式 | 危险信号 |
| :--- | :--- | :--- | :--- |
| **营销** | CAC | (营销费 + 销售成本) / 新增付费 | > LTV / 3 |
| | LTV | ARPU × 毛利率 / 流失率 | — |
| | Payback | CAC / (ARPU × 毛利率) | > 12 个月 |
| | 渠道结构健康度 | 单一渠道占比 | 单渠道 > 60%（一断就死） |
| **策划** | 3 秒记忆率 | 能复述单一信息的受访者 / 受访者 | < 40% |
| | 内容互动率 | (赞+评+转+藏) / 曝光 | < 2%（图文） |
| | 素材胜出率 | 跑赢组内均值的素材 / 总素材 | < 20% |
| **推广** | 品牌词搜索量 | 搜索后台 | 长期为 0 |
| | 自然注册占比 | 自然来源注册 / 总注册 | < 20% |
| | 外部提及数 | 舆情 / 搜索 | 0（说明没人讨论） |
| | 分享率 | 分享 / 阅读 | < 1% |
| **投放** | CPM | 花费 / 曝光 × 1000 | 同类素材波动 > 50% |
| | CTR | 点击 / 曝光 | < 0.8%（信息流） |
| | CVR | 转化 / 点击 | < 2%（注册类） |
| | CPA | 花费 / 转化 | > 1.3 × 目标 |
| | ROAS | 收入 / 花费 | < 1 / 毛利率 |
| **全局** | 激活率 | 完成关键动作 / 注册 | < 40%（工具类） |
| | D7 / D30 留存 | 第 7/30 日仍活跃 / 首日 | D7 < 20% |
| | NPS | 推荐者% − 贬损者% | < 30 |

> 与 `economics-formulas.md` 的分工：那边算"能不能活"（LTV/CAC/COGS），这边算"钱花得值不值"（CPA/ROAS/留存/声量）。

## 6. 案例

### 6.1 营销层案例（管全局：定位与增长模型决定一切）

| 案例 | 做法 | 可迁移机制 | 不要照抄 |
| :--- | :--- | :--- | :--- |
| **HubSpot 入站体系** | 用内容矩阵 + 免费工具做长期 inbound，把 SEO 资产变成获客管道 | 营销先定"内容驱动"模型，再反推渠道与预算 | 需要 12~24 个月才见效，现金流撑不住别学 |
| **Notion 的定位** | 用"all-in-one workspace"统合多个使用场景 | 定位决定渠道：场景越统一，内容越容易复用 | 定位过宽会失去记忆点，需要极强的产品力兜底 |

### 6.2 策划层案例（出主意：一个机制就是一个创意）

| 案例 | 做法 | 可迁移机制 | 不要照抄 |
| :--- | :--- | :--- | :--- |
| **Dropbox 双面推荐** | 邀请双方都得存储空间 | 把"推荐"设计成产品内动作，创意即机制 | 没有天然可赠送的额度（存储/次数），激励会变成纯现金成本 |
| **Superhuman 邀请制** | 邀请码 + 1:1 上手 | 稀缺感 + 高触达 onboarding 本身就是创意 | 人力密集，规模不经济，只适合高客单 |

### 6.3 推广层案例（造声量：不花钱的放大）

| 案例 | 做法 | 可迁移机制 | 不要照抄 |
| :--- | :--- | :--- | :--- |
| **Airbnb 早期** | 借 Craigslist 已有流量交叉发布 | 寄生已有流量池，比自建快 10 倍 | 平台一封即归零，只能当跳板 |
| **Notion 模板与社区** | 用户产出模板，模板页自带搜索流量 | 用户生成资产 = 分发资产（UGC 即 SEO） | 前提是产品"可被展示"，纯后台工具没有展示物 |
| **Figma 社区 / 插件** | 供给侧内容拉动需求侧，团队内自然扩散 | 生态型推广：让别人替你生产传播素材 | 需要开放平台能力，否则生态起不来 |
| **Product Hunt 发布** | 单日集中所有渠道打一次 | 把注意力压缩成峰值 | 一次性事件，复购型 B2B 的第二曲线不在这里 |

### 6.4 投放层案例（买曝光）：一个诚实的说明

> **公开可核验的账户级投放数据几乎没有**：网上流传的"某产品 ROAS 8"多为二手且无法验证。本手册不编案例，只给可执行的规则（§4）与可复用的复盘表（§7.4）。真要案例，用你自己的账户跑一轮 24 条素材矩阵，比看十篇"爆量复盘"有用。

### 6.6 反例：四种死法分别死在哪一层

| 死法 | 表面症状 | 真实病根（哪一层） |
| :--- | :--- | :--- |
| 渠道错配 | 点击便宜但全是无效人群 | **营销**：ICP 没定清，渠道当然选错 |
| 素材疲劳 | CTR 腰斩还加大预算 | **策划**：产能不足，没有新弹药 |
| 归因自嗨 | 只报 last-click，越投越"有效" | **投放 / BI**：没有增量验证 |
| 假 PMF | 靠大折扣冲一批用户，D7 只剩 10% | **营销**：把"促销响应"当成"需求验证" |

### 7.2 策划：Creative Brief + 内容日历


## 8. 与 7 阶段 / 12 角色的对应

| 层 | 主要阶段 | 对应角色 | 卡点前必须交付 | 不通过就不许推进 |
| :--- | :--- | :--- | :--- | :--- |
| **① 营销** | 阶段 0 / 1 | CMO（营销策划官）+ CFO | 定位四件套、增长模型、目标数字、预算配比 | 5 人复述测试不过；无目标 CPA |
| **② 策划** | 阶段 0 / 2 / 6 | CMO（创意）+ UI/UX | Big Idea、Creative Brief、内容日历、素材脚本 | 一条素材讲多个卖点；无可分享点 |
| **③ 推广** | 阶段 0 / 6 | Growth（推广） | 渠道打分表、1 主 2 测、UTM 与落地页、SOP、排期 | 渠道算不出单客成本 |
| **④ 投放** | 阶段 1 / 6 | Growth（投放）/ 专职投手 | 三条线、账户结构、素材矩阵、止损规则、归因方案 | 无止损线；只报 last-click |

> **组织提醒**：12 角色里没有独立的"投手"。当日预算超过「3 × 目标 CPA × 20 个广告组」这个量级时，投放应从 Growth 拆出专职角色，否则既做内容又管账户，两边都会松。
