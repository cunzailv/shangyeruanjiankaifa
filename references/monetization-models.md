# 变现模式库与副业单位经济 (Monetization Models & Micro-Business Economics)

> **用途**：阶段 0 判断"这是不是一门真生意"、阶段 1 给"启动成本 / 客单 / 毛利 / 回本条件"找参数、阶段 6 选冷启动动作。
> **来源与授权**：数据与思想抽取自开源项目 [`XiaomingX/ai-money-maker-handbook`](https://github.com/XiaomingX/ai-money-maker-handbook)（Apache-2.0），含《程序员的副业赚钱宝典》444 章与《创业者早期的烦恼树洞》69 篇。文中每条数字后标了章节号，可回溯原文。
> **重要口径**：该书所有金额均为作者**预估模型**（不是实测财报）。本文保留原区间、不做四舍五入美化；引用时必须带"预估"字样，**不得当作收益承诺**。

## 0. 先说结论：这本书最值钱的三句话

1. **做资产，不卖时间**——一份时间卖一次是打工，卖多次才是生意。
2. **卖铲子，不挖金子**——做工具/基础设施的风险，远低于自己下场做内容赌爆款。
3. **不想花钱就花时间**——0 预算阶段的唯一杠杆是内容与试错次数，不是投放技巧。

对应到我们的 7 阶段：这三句话决定了阶段 0 的"验真重点"和阶段 1 的"成本结构假设"。

**两个立刻能用的推导**：

- **回本订阅用户数** = 启动成本 ÷（月客单 × 毛利率）。例：¥1,000 ÷（¥15 × 0.9）≈ 74 个付费用户回本（不含人力）。
- **B 端 SaaS 的生死线** = CAC ÷（年单价 × 毛利率）→ 例：¥300 ÷（¥1,980 × 0.98）≈ 0.15 年，即**首年就要收回获客成本**，否则续费率必须 > 80% 才成立。

## 3. 冷启动方法库（0 预算阶段的六个招式）

| 招式 | 怎么做（一句话） | 适用模型 | 出处 |
| :--- | :--- | :--- | :--- |
| **报错长尾 SEO** | 写"HTTP 502 / 超时 / 部署失败"这类具体报错文，文末给自己的工具 | API / SDK / 工具 | ch0034 |
| **开源 Demo 木马** | 发 1–2 个开箱即用的 Demo，核心调用依赖你的 SDK | SDK / 中间件 | ch0034 |
| **社群技术顾问人设** | 关键词监控 + 只回问题不发广告，签名里带工具 | B 端 / 服务 | ch0034 |
| **资料包裂变** | 高价值 PDF，领取需转发或拉 3 位好友 | 知识付费 / 社群 | ch0014 |
| **矩阵赛马** | 3–5 个账号同题不同风格，前 5 篇定生死，赢的加注 | 内容 IP / 流量 | ch0009 |
| **私域沉没成本** | 让用户存数据/存配置，半小时内响应反馈 | 订阅工具 | ch0017 |

**判断标准**：一个招式跑 2 周，若"新增注册 < 30 且单客成本算不出来"，换下一个，别同时开三个。

## 4. 早期验证与增长判据（来自《创业者早期的烦恼树洞》）

### 4.1 PMF 的三类信号（不是"感觉好用"）

| 维度 | 信号 |
| :--- | :--- |
| 用户端 | 留存稳定在行业健康线以上、NPS > 20、用户**主动提需求** |
| 市场端 | 份额自然增长、竞品开始模仿、付费比例上升 |
| 业务端 | 营收增长不靠烧钱、利润率逐步提升 |

**两个验证法**：① **反向验证**——停掉推广，看自然增长是否还在；② **问题解决率**——问核心用户"这个问题被解决了多少"。（ch0001）

### 4.2 PMF 之前的财务健康（本质是"活下来"）

| 指标 | 底线 |
| :--- | :--- |
| 现金流 | 月末现金可覆盖未来 **3–6 个月**支出 |
| 烧钱率 / 跑道（Runway） | 至少 **6–12 个月**；不足就砍支出或融资 |
| 资金储备 | ≥ **6 个月**烧钱率，不投长期资产 |

三个保命动作：滚动现金流预测、按必要性砍支出、**预收款**（预售套餐 / 定金尾款）。（ch0003）

### 4.3 虚荣指标鉴别（DAU 高但不赚钱）

出现"DAU 翻倍 + ARPU 下降 + CAC 上升 + 停投即腰斩"四项中的三项，基本可判定为虚荣增长。三个对策：北极星指标换成**次日留存与 LTV**、做**零投放自然增长测试**、把买量的钱转去做存量复购。（ch0064）

## 5. 红线与资质清单（这些"副业"不要碰）

> 原书对灰色地带做过标注，这里整理成**判定表**。原则：不做、不包装、不提供操作细节；确有资质的，先拿资质再谈。

| 类型 | 风险依据 | 我们的处理 |
| :--- | :--- | :--- |
| **AI 论文代写 / 降重代投** | 学术不端，学校与期刊查处，平台封禁 | **不做**；只做"合规润色、结构建议、引用规范检查" |
| **视频搬运 / 翻译搬运** | 著作权侵权、平台侵权投诉 | **不做**；只做获得授权的内容 |
| **卖 AI 账号 / 发卡站 / API 中转** | 违反上游服务条款，封号、支付与资金风险，可能涉非法经营 | **不做**；只用官方 API 与合规代理 |
| **小游戏/小程序代理投流、跨境广告代投** | 需广告与开户资质，易涉欺诈与违规开户 | 需资质 + 书面授权，否则不做 |
| **金融资讯、小额贷款、荐股类服务** | 需证券投顾 / 放贷等牌照 | **不做**；只做工具与公开信息整理，不提供投资建议 |
| **游戏代练 / 私服 / 外挂** | 违反游戏条款、著作权，可能涉破坏计算机信息系统 | **不做** |
| **爬取简历 / 通讯录 / 个人数据** | 违反《个人信息保护法》，涉敏感个人信息 | **不做**；只用公开数据或已授权数据 |
| **拿原公司代码/架构/数据做副业** | 侵犯商业秘密与著作权 | 必须**从零重写**、彻底脱敏（ch0142、ch0136、ch0139） |
| **域名/商标抢注套利** | UDRP 仲裁、商标侵权，可能被无偿收回（ch0143） | 只做无冲突命名 |
| **"保 offer / 保收益 / 稳赚"式宣传** | 违反广告法，平台直接封禁 | 禁止；只报可复现的过程数据 |

## 6. 怎么接进 7 阶段

| 阶段 | 用这份文档做什么 | 产出 |
| :--- | :--- | :--- |
| **阶段 0 验真** | ① 十类模型里先圈定 1–2 个候选；② 做 10–20 个精准用户对话；③ 用"假门把手/预售"测付费意愿；④ 扒竞品差评找空白 | 《需求验真报告》含"模型候选 + 付费证据" |
| **阶段 1 测算** | 用 §2 参数库带入自己的数字，算回本用户数、CAC 上限、跑道；用 §4.2 检查"能不能活" | 《单位经济测算》含 LTV/CAC、回本周期、Runway |
| **阶段 2 PRD** | 按选定模型裁剪功能：订阅工具先做"一个高频动作"，B 端 SaaS 先做"一条流程闭环" | PRD 的 MVP 边界 |
| **阶段 6 冷启动** | 从 §3 选 1–2 个招式，配 2 周判定线 | 冷启动 SOP + 止损线 |

**一条硬规则**：阶段 1 若算不出"回本用户数"或"Runway < 6 个月"，不允许进入开发。
