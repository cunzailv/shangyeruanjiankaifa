# 商业测算与单位经济学 (Unit Economics) 核心公式参考手册

在执行 **阶段 1 (商业模式、变现路径与单位经济学测算)** 时，请严格使用以下公式体系进行财务推演。

## 1. 核心商业健康度指标 (Core Metrics)

*   **CAC (Customer Acquisition Cost) 单客获取成本**:
    *   公式：`CAC = (营销与广告总费用 + 销售团队成本) / 新增付费客户数`
    *   *要求*：必须低于 LTV 的 1/3。
*   **LTV (Customer Lifetime Value) 单客生命周期价值**:
    *   公式：`LTV = (ARPU × 毛利率) / Churn Rate`
    *   *(ARPU: 平均单客月收入, Churn Rate: 月流失率)*
*   **健康度红线 (Health Ratio)**:
    *   标准健康状态：`LTV : CAC ≥ 3 : 1`
    *   卓越状态：`LTV : CAC ≥ 5 : 1`
*   **回本周期 (Payback Period)**:
    *   公式：`回本周期 (月) = CAC / (ARPU × 毛利率)`
    *   *要求*：SaaS 产品最好控制在 6 - 12 个月内。

## 2. AIGC 产品专属成本拆解 (AIGC COGS Breakdown)

每次用户触发核心 AI 动作（如生成一篇文章、一张图），必须核算单次请求成本（COGS per Action）：

*   **LLM 文本/代码生成成本**:
    *   `单次成本 = (输入 Token 数 / 1000 × 输入单价) + (输出 Token 数 / 1000 × 输出单价)`
    *   *(注：提示词包含系统预设、上下文和 RAG 检索结果，通常输入 Token 是输出的 5-10 倍)*
*   **多模态生成（图片/视频/语音）成本**:
    *   `单次成本 = API 按次计费 / 算力节点按秒计费 + (生成文件大小 × 对象存储出网费率)`
*   **防破产底线 (Anti-Bankruptcy)**:
    *   禁止使用按流量双向计费的云存储（如 AWS S3）直接对外暴露大文件，强制替换为零出网费服务（如 Cloudflare R2）。
    *   免费层（Freemium）必须设置硬性 API 限流（Rate Limit）与单日 Token 消耗阈值。

## 3. SaaS 定价阶梯建议 (Pricing Tiers Best Practices)

*   **Hobby (免费/引流层)**：零利润或微亏，仅开放基础功能，强制加上产品水印，严格限流。
*   **Pro (核心利润层)**：目标毛利率 75% - 85%。定价应为每月 `单客预期 AI 消耗总成本 × 4` 到 `× 5`。
*   **Team/Enterprise (高客单层)**：基于坐席（Per Seat）收费，支持 SSO/SAML，提供私有数据隔离与优先 SLA 支持。毛利率应达 90% 以上。

## 4. PMF 之前的财务健康：先算"能活几个月"

PMF 完成前不追求盈利，只守"现金生命线"。阶段 1 必须同时给出下面三个数，缺一个就算没算完：

*   **跑道 (Runway)**：`Runway(月) = 账面现金 / 月净烧钱率`
    *   底线：**6 – 12 个月**；低于 6 个月，禁止开新功能、禁止扩编。
*   **现金安全垫**：`安全垫 = 6 × 月烧钱率`
    *   低于安全垫时，优先动作是"砍支出 + 预收款"，不是融资 or 投放。
*   **滚动现金流预测**：按周滚动未来 13 周，标出"最低现金点"出现的周次。
*   **预收款杠杆**：预售套餐、定金 + 尾款，把未来的钱提前到今天（不改变毛利，只改变现金时点）。

## 5. LTV 的两套口径（用错会差好几倍）

| 业务形态 | 公式 | 适用 |
| :--- | :--- | :--- |
| **持续订阅型**（SaaS/会员，用户长期留存） | `LTV = ARPU × 毛利率 / Churn` | 月流失率稳定、生命周期长 |
| **短周期 / 任务型**（求职、考试、婚恋、活动类） | `LTV = ARPPU × 毛利率 × 平均付费月数` | 目的达成即流失，**不能用 1/Churn** |

> `1 / Churn` 隐含"用户无限期续费"，任务型产品会高估数倍。示例：ARPPU ¥37、毛利 85%、付费 2.5 个月 → LTV ≈ ¥79；若误用 Churn 5% 会算出 ¥629。

**初创简化三步法**（数据不全时用）：① 定义生命周期（如"连续 2 个月不活跃即流失"）；② 每月贡献只算毛利；③ 总毛利 ÷ 新用户数 = LTV。要求"相对合理"，不追求精确。

**LTV : CAC 分档处置**：

| 比值 | 处置 |
| :--- | :--- |
| ≥ 3 | 健康，可加投、可立项 |
| 2 – 3 | 只允许"验证性预算"，单渠道小额测试 |
| 1.5 – 2 | 只能做实验，不得放量 |
| < 1.5 | 立即停该渠道 |

## 6. 定价：成本定底线，测试定上限

*   **保本销量**：`Q = 固定成本 / (单价 - 单位可变成本)`
    *   示例：固定成本 ¥80,000/月，单位可变成本 ¥30，定价 ¥80 → `80,000 / 50 = 1,600 件/月`。
*   **盈亏平衡价**：`P = 单位可变成本 + 固定成本 / 预计销量`
*   **三档定价 + 锚点**：见 §3（Hobby / Pro / Team），中间档为主推，最高档负责衬托。
*   **测上限的三种低成本手段**：预售（先收钱再交付）、阶梯价（早鸟/标准/团队）、试用装（限量免费换反馈）。
*   **年付折扣**：15% – 20% 是常见区间，本质是用折扣换现金流与留存，不是"打折促销"。

## 7. 虚荣指标鉴别（DAU 涨、收入不涨）

出现下列四项中的**三项**，判定为虚荣增长：

1. DAU / 注册量上涨，但 ARPU 下降；
2. CAC 持续上升；
3. 停投后数据腰斩；
4. 收入增长依赖折扣或补贴。

**指标替换表**：

| 虚荣指标 | 换成 |
| :--- | :--- |
| DAU / 注册数 | 次日留存、激活率（完成关键动作） |
| 下载量 | 付费转化率 |
| GMV | 退款后净收入 |
| 曝光量 | 品牌词搜索量、自然注册 |
| 用户总数 | 周活付费用户 |

三个对策：北极星换成留存与 LTV、做零投放自然增长测试、把买量的钱转去做存量复购。

## 8. 副业三笔账：时间账 / 现金账 / 资产账

| 账 | 公式 | 判定 |
| :--- | :--- | :--- |
| **时间账** | `单位时间产值 = 时薪 × 杠杆倍数`（杠杆 = 同一份产出可复用/可售卖次数） | 杠杆 = 1 是打工；≥ 10 才算产品化 |
| **现金账** | `回本月数 = 启动成本 / 月净利` | > 6 个月要缩启动成本或提价 |
| **资产账** | `被动收入占比 = 无需投入工时的收入 / 总收入` | < 30% 说明仍在卖时间 |

**决策规则**：三笔账里有两笔为负（时间不增值、现金不回本、资产不积累），换模型而不是"再努力一点"。
